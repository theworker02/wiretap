# Brand

Wiretap’s visual language is **instrumentation**: a clean signal trace and a single
tap probe — minimal, sharp, readable. Not purple glow, not generic AI chrome.

Maintainer: [@theworker02](https://github.com/theworker02)

Canonical assets live in [`assets/`](../assets/).

| File | Use |
|------|-----|
| [`logo.svg`](../assets/logo.svg) | Dark wordmark + mark (README, dark UIs) |

```css
  --wt-fg-muted: #7d949c;

```

## Typography

- **Wordmark:** system monospace, wide letter-spacing
- **Body:** system UI sans

## Do / don’t

**Do:** dark instrument panels, teal→copper signal, monospace CLI, honest tone.  
**Don’t:** purple/indigo AI gradients, neon glow stacks, fake confidence meters.
